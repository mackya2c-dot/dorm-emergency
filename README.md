# 寮 緊急時対応ガイド（PWA）セットアップ手順

## 構成
- `github/` … GitHubリポジトリに置くファイル一式（PWA本体）
- `gas/Code.gs` … スプレッドシートに貼るGAS（編集・公開・PDF・ログ受信）

`github/data/` にはサンプルデータ（架空の連絡先）が暗号化済みで入っています。
パスコード：`sample-pass-2026`（動作確認用。GASから公開すると置き換わります）

## A. GitHubにアップロード
1. 手元でZipを展開し、`github` フォルダを開く
2. リポジトリの画面で「Add file」→「Upload files」
3. `github` フォルダの中身（index.html、app.js、style.css、sw.js、manifest.webmanifest、robots.txt、icons フォルダ、data フォルダ）をまとめてドラッグ
4. 「Commit changes」→ 数分待つ
5. スマホで https://ユーザー名.github.io/リポジトリ名/ を開き、名前とサンプルのパスコードを入力して動作確認
6. iPhoneはSafariの共有ボタン →「ホーム画面に追加」。機内モードで開けることを確認

## B. スプレッドシートとGAS
1. 新しいスプレッドシートを作成 →「拡張機能」→「Apps Script」
2. Code.gs の中身を全部置き換えて保存 → スプレッドシートを再読み込み
3. メニュー「緊急対応フロー」→「① 初期設定」（初回は権限の承認が必要）
4. 「設定」シートに GitHubユーザー名・パスコード（8文字以上）を入力
5. メニュー「② GitHubトークンを登録」でトークンを貼り付け
6. 「分岐をチェック」→「GitHubへ公開」

## C. 対応記録（ログ）の受信
1. Apps Script画面「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
2. 実行ユーザー：自分 ／ アクセスできるユーザー：全員
3. 表示されたURLを「設定」シートの「ログ受信URL」に貼り付け →「GitHubへ公開」
※ コードを変更したら「デプロイを管理」→ 編集 →「新バージョン」で更新

## アプリ本体を修正したとき
sw.js の CACHE = 'emg-shell-v1' の番号を上げてからアップロードする（上げないと端末に反映されません）。
データ（フローの中身）の更新はGASの「公開」だけでよく、この作業は不要です。
